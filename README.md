# CSS Weekly #01

Open `index.html` in a browser. The presentation works offline; the two activity links on Slide 6 need an internet connection.

- Left and right arrows, Page Up and Page Down: change slides
- Home and End: first and last slide
- F: fullscreen
- P: print all eight slides

The visual style adapts [CSS Photo Club Design 2](https://github.com/Yoonjae7/cssphotoclub): its dark retro computer windows, lavender borders, mint cursor, Pixelify Sans type, and terminal footer. The CSS logo and the bundled Pixelify Sans and DM Sans fonts come from that repository. Font licenses are in `assets/fonts/`.

Slide 7 contains two independent CS Fair diagrams: membership/T-shirt purchases and booth activities. Edit the inline SVG text and connectors in `index.html`; styles use the deck’s bundled fonts and palette in `styles.css`. Stock is 29 T-shirts. Preorders preserve the selected price, including bundle and eligible winner discounts. Activity access without a purchase remains a draft assumption.
